🧗 Pull-up Progression

Done in every Strength A & B session. Daily homework: 30s dead hang + 5 scapular pull-ups (takes 2 min, do before bed with mobility)

PhaseIn Session (Mon & Sat)Key Cue
Phase 1Band-assisted 3×5 + Negatives 3×5 (3s down)Build grip & lat activation
Phase 2Lighter band 3×5 + Negatives 3×5 (5s down) + 1 unassisted attemptSlow negatives are king
Phase 3Lightest band 3×3 + Unassisted attempts (up to 5 singles)Grease the groove
Phase 4Unassisted pull-ups 🎯 (even 1 rep = victory!)You’ve earned this

💡 First pull-up typically takes 4–6 months for women. This plan is 19 weeks — stay consistent with the daily homework and it’s very achievable.

🚀 v4 Upgrades (Strength-first guardrails)

Traffic Light Readiness

  • Green: Sleep/recovery good → run full session as written
  • Yellow: Heavy legs / poor sleep → reduce one variable (volume or intensity)
  • Red: Niggle/pain or 2 bad sessions in a row → deload 30-40% for 5-7 days

Saturday Strength B Rule

  • Keep lower-body compounds at RPE 7-8 (avoid grinders) to protect Sunday long run quality
  • If Thu TSS was a crusher, drop one lower-body set on Saturday

Friday Recovery Run Rule

  • Optional run stays very easy only (conversational, short)
  • Skip without guilt if legs are heavy

Pull-up + Core Upgrade

  • Keep daily dead hang + scap pulls (2 min)
  • Add 1-2 easy micro-sets on Tue/Thu if fresh (never to fatigue)
  • Copenhagens replace dead bugs in Session A; progress from short-lever holds in Phase 1-2 to longer holds in Phase 3-4

Simple 4-Week Checkpoints

  • Track: best dead hang time, best assisted/unassisted pull-up effort, and one controlled run marker (e.g., 1km check)

🎯 v5 Performance Protocol (8.3 → 10/10)

1) Auto-Regulation Rules (Non-Negotiable)

  • If Thu TSS feels hard (RPE 8+): Sat Strength B lower-body compounds drop by 1-2 sets
  • If 2 fatigue flags in one week: convert Wed quality run to easy aerobic (30-45 min)
  • If pain is >3/10 or changes gait: switch to 5-7 day deload immediately

2) Weekly Readiness Dashboard

Rule: 0-1 yellow = train as planned. 2 yellow = reduce one variable (volume or intensity). Any red = deload protocol.

3) Race/Test Week Precision

  • W9 (10K TT) + W18 (5K TT): Saturday is always light/upper-focused, no heavy lower-body grinding
  • In W10-14, only include long-run fast finish every second week (not weekly)
  • If late Phase 3 fatigue appears, add a mini-reset week (run volume -20%, lower-body sets -30%)

4) Strength Progression Specificity

  • Back squat / RDL progression: add load only when top set is RPE ≤8 for 2 consecutive weeks
  • Suggested increment: +2.5kg (or smallest plate jump) next week
  • If top set is RPE 9+, keep load and reduce one accessory set

5) Pull-up Advancement Criteria

  • Advance band level when all sets are completed with clean form and no kipping for 2 weeks
  • Track weekly: best dead hang time + best unassisted attempt quality
  • Keep Tue/Thu micro-dose (1-2 easy sets) only if shoulders/elbows feel fresh

6) Durability Add-Ons (2x/week)

  • Standing calf raise: 3×12-15
  • Bent-knee soleus raise: 3×12-15
  • Copenhagen progression: short lever → longer holds/lever as tolerated

7) Monthly Review Loop (every 4 weeks)

  • What improved? (strength numbers, pull-up metrics, pace tolerance)
  • What stalled? (specific lift or run session type)
  • What caused fatigue spikes? (sleep, TSS intensity, recovery run creep)
  • Adjust next 4 weeks based on data, not motivation
