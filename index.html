Progression Rules

Lift TypeHow to ProgressNotes
Main lower body lifts Add 2.5–5 kg when all reps are clean Squat, deadlift, RDL
Main upper body lifts Add 1–2.5 kg when all reps are clean Bench, OHP
Rows / split squat / pull work Add reps first, then add load Example: 3x6 → 3x7 → 3x8, then increase weight
Calves Stay in the range and push smooth reps Don’t turn them into bounce reps from hell

If bar speed is ugly, hold the weight. This is a strength block, not an ego block.

Optional Extras

  • Pull-up work: assisted pull-ups, slow eccentrics, top holds, or dead hangs.
  • Calves / lower leg: extra bent-knee calf raises, straight-knee calf raises, or tib raises.
  • Core: side planks, dead bugs, Pallof press, or loaded carries.
  • Single-leg control: step-downs, light step-ups, or lateral band walks if recovery is good.
  • Upper back / shoulder health: face pulls, band pull-aparts, or rear delt work.

Add extras only after the main lifts are done, and only if they don’t make the main program worse.

If your knee flares up…

  • Keep it simple: wall sits or Spanish squats, step-downs, split squats, bent-knee calf raises, and lateral band walks are your best first-line extras.
  • Reduce intensity first: back off hills, faster running, and aggressive lower-body fatigue before you slash everything else.
  • Use the pain rule: mild awareness is okay, sharp pain or worsening pain is not.
  • Best tiny routine: wall sit 2 x 30–45s, step-downs 2 x 6–8/side, bent-knee calf raises 2 x 12–15, band walks 1–2 x 10–15 steps each way.

Think “calm it down and improve control,” not “punish it into behaving.”

Notes

  • Monday is flexible: use it for an optional easy run, cross-training, or full rest depending on fatigue.
  • Keep running simple: Wednesday and Sunday are your main run days, with Sunday as the long run and strides added to Wednesday.
  • If recovery gets rough: reduce accessory volume first, not the core lifts.
  • Goal of the block: finish stronger, more stable, and ready to transition into a 5K block — not utterly cooked.
