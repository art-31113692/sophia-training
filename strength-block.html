Weekly Session Templates

Day 1

  • Back Squat — main squat pattern
  • Bench Press — horizontal press
  • Barbell Row — upper back / pulling
  • Straight-knee calf raise — gastroc focus

Day 2

  • Deadlift — main hinge
  • Overhead Press — vertical press
  • Split Squat — single-leg strength
  • Pull-up / Pulldown — vertical pull

Day 3

  • Front or Pause Squat — secondary squat
  • Incline Bench — secondary press
  • Romanian Deadlift — posterior chain
  • Pull-up / Pulldown — vertical pull
  • Bent-knee calf raise — soleus focus

Progression Rules

Lift TypeHow to ProgressNotes
Main lower body lifts Add 2.5–5 kg when all reps are clean Squat, deadlift, front/pause squat
Main upper body lifts Add 1–2.5 kg when all reps are clean Bench, incline bench, OHP
Rows / RDL / split squat / pull work Add reps first, then add load Example: 3x6 → 3x7 → 3x8, then increase weight
Calves Stay in the range and push smooth reps Don’t turn them into bounce reps from hell

Notes

  • Keep running simple: usually 2 easy runs per week, with strides once weekly.
  • If recovery gets rough: reduce accessory volume first, not the core lifts.
  • Count Strength Syndicate as load: if Thursday class is spicy, treat it as a real training stress.
  • Goal of the block: finish stronger, more stable, and ready to transition into a 5K block — not utterly cooked.
